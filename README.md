# Sonara

Client Android per YouTube Music (solo audio) con il motore audio di MLPlayer:
equalizzatore (Parametrico, AutoEQ, Grafico), DSP, uscita Hi-Res e interfaccia Material Design 3.

Stato: in costruzione. Base copiata da MLPlayer; il livello YouTube Music è in sviluppo.
